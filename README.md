# capstone-team3


## Project Overview
This repository contains the source code and documentation for Capstone Project.  
The project is structured to follow professional software development standards with clear separation of frontend, backend, and documentation components.

---

# Repository Structure

frontend/        → User Interface (UI)  
backend/         → API / Server-side logic  
documentation/   → Business case, requirements, meeting notes, diagrams  

---

## Folder Details

### frontend/
Contains all user interface related code (React / Next.js / etc.).  
Includes components, pages, styling, and client-side logic.

### backend/
Contains API routes, server logic, authentication, database connections, and business logic.

### documentation/
Contains all non-code project materials:
- Business Case
- Requirements Specification
- Meeting Notes
- Architecture Diagrams
- Technical Documentation
- Project Planning Documents

---

# Development Workflow

To maintain clean collaboration and avoid conflicts, all team members must follow this workflow:

---

## Create a Feature Branch

Each team member must create a branch using the naming convention:

feature/<name>-<task>

Example:
feature/anish-login-api  
feature/deepesh-dashboard-ui  

---

## Pull Latest Changes Before Starting Work

Always update your local repository:

git pull origin main

---

## Commit Your Changes

After completing your task:

git add .  
git commit -m "Clear and meaningful description of changes"  
git push origin feature/<name>-<task>  

---

## Create a Pull Request (PR)

- Go to GitHub repository
- Click "Compare & pull request"
- Add a clear description of what you implemented
- Submit the PR to merge into main
